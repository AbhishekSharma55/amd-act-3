Challenges

Solve a real Business Problem with AMD technology

Track by partner: Evolus

Evolus Business Agents on AMD

Build an AI agent that runs a real business process end to end, on Evolus, powered by an open model served on AMD.

Pick a process that a real company runs every day and let an agent run it. The agent takes the input (an email, a PDF, a recording, a web form, a chat), reasons over it with an open model running on AMD, and acts: it runs an Evolus workflow, turns documents into data, uses AI Tools, updates another system, or hands the case to a person when it should.

Requirements

  1. Build in a free Evolus event workspace, created at app.evolus.ai with the event code shared at kickoff.
  2. Bring your own model: the main agent must use an open model served on AMD infrastructure through your own vLLM endpoint on AMD Developer Cloud.
  3. Use at least two Evolus building blocks: workflows, document extractors, AI Tools, knowledge libraries, MCP connectors, sub-agents, chat widget.
  4. Drive Evolus from your app through its APIs: the Evolus REST API for workflows, extractors, AI Tools and libraries; agent chat through the REST API or the OpenAI-compatible endpoint.
  5. Follow the hackathon submission rules: containerized app, public GitHub repository, a README that runs. Never commit API keys: use environment variables.

Sample use cases

Use case Input What the solution does
Invoice and order intake Emails with PDF attachments A workflow started by incoming email reads the PDF, extracts the fields into JSON, matches them to the order and flags mismatches to a person
Support desk on company knowledge Chat, email or website widget An agent answers from the company’s documents with sources and passes the case to a person when unsure
Lead qualification Chat widget on a website Qualifies the visitor, books a call and pushes the lead to a CRM through MCP
Contract review Uploaded contracts Extracts key clauses, compares them with the company’s standard terms and redacts personal data before sharing
Multilingual documents PDF and Word files Translates manuals and offers keeping their layout, then files them through a workflow
Meeting follow-up Recordings of calls and meetings Turns the recording into minutes and action items and sends them to the attendees

Technology

Technology & access

Teams connect their own model and build around it: agents, business automations, document extractors, knowledge libraries and ready-made AI Tools, all driven by API.

Agents and sub-agents

Agents with tools and memory, running on the team’s own model.

Evolus REST API (ask, streaming ask-stream); for chat also the OpenAI-compatible /v1/chat/completions

Workflows (business automations)

Multi-step pipelines of agents, document reading, extractors and webhooks, with branches, loops and parallel steps. They start from an API call, an incoming email or a schedule: files in, result out to a callback URL.

Evolus REST API: POST /api/v1/workflows/{id}/execute with text and files, then the execution status

Document extractors

Turn PDFs, scans and images into structured JSON, following a schema you define.

Evolus REST API, or as a workflow step

AI Tools

Eleven ready-made tools: document to structured data (JSON, CSV, XML), table extraction, translation of PDF and Word files keeping the original layout, real redaction of personal data in PDFs, summaries, meeting minutes from audio or video, email writing and replies, rewriting, plain-language simplification, sentiment, comparison of two texts.

Evolus REST API: /api/v1/ai-tools/{tool}/run, run-media for audio and video, run-file for file in, file out

Knowledge libraries (RAG)

Upload documents or import web pages; agents answer from them, with sources.

Evolus REST API, attached to agents

Webhooks

Notify your own systems when something happens.

Evolus REST API

MCP connectors

Connect agents to external systems through MCP servers, including your own.
