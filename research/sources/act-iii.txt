Track by partner: Evolus
Evolus Business Agents on AMD
Build an AI agent that runs a real business process end to end, on Evolus, powered by an open model served on AMD.
Pick a process that a real company runs every day and let an agent run it. The agent takes the input (an email, a PDF, a recording, a web form, a chat), reasons over it with an open model running on AMD, and acts: it runs an Evolus workflow, turns documents into data, uses AI Tools, updates another system, or hands the case to a person when it should.
Requirements
Build in a free Evolus event workspace
, created at
app.evolus.ai
with the event code shared at kickoff.
Bring your own model:
the main agent must use an open model served on AMD infrastructure through your own vLLM endpoint on AMD Developer Cloud.
Use at least two Evolus building blocks:
workflows, document extractors, AI Tools, knowledge libraries, MCP connectors, sub-agents, chat widget.
Drive Evolus from your app through its APIs:
the Evolus REST API for workflows, extractors, AI Tools and libraries; agent chat through the REST API or the OpenAI-compatible endpoint.
Follow the hackathon submission rules:
containerized app, public GitHub repository, a README that runs. Never commit API keys: use environment variables.
