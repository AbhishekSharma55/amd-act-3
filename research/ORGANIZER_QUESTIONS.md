# Organizer clarification draft

Prepared for the participant to review/use in the official event channels. **Nothing has been sent.**

Hello! We are participating online in AMD Developer Hackathon: ACT III and want to verify these requirements before committing our architecture and submission package:

1. **Online submission deadline:** What is the exact final submission cutoff in UTC? The event schedule lists October 18 at 12:00 CEST, while the Milan/Imperia venue agendas list 16:00. The public event end is October 18 at 15:00 UTC, and a generic timeline row still says October 17. Which timestamp controls online submission and updates?

2. **Main AMD awards and judging:** How is the $5,000 AMD pool divided? Is there an overall first place, challenge-specific awards, or both? Do online and on-site teams compete for the same awards? What are the judging stages, criterion weights, and tie-breaking rules? How can an online team participate in any live judging?

3. **Google awards:** Which models or technologies qualify for the $5,000 Google pool? Is Gemma required, and which serving routes are eligible? Is a specific opt-in required? Can a submission win both the main AMD and Google awards?

4. **Evolus model route:** The lablab brief requires an owned vLLM endpoint on AMD Developer Cloud. Evolus's own event article also accepts Fireworks. Does an open model through AMD Token Factory qualify for the Evolus award? Which rule should we follow? We understand that the free workspace must be created through the event-specific join route.

5. **Technical submission and judging access:** Are containers mandatory for all main challenges or only the Evolus track? If required, what image format, CPU architecture, runtime contract, credentials, resource limits, and automated endpoints are expected? How long must the application and AMD inference endpoint stay available after submission? What video/upload limits apply in the active form?

6. **Challenge fit and originality:** Can a principally infrastructure/developer-tool project compete under one of the four main challenges when it demonstrates a business benefit? How should pre-existing scaffolds be disclosed, and what new work is required? Can one entry select multiple main challenges?

Thank you! We will plan against the earliest published submission deadline until the cutoff is clarified.
